# TravelAI — AI-Powered Smart Travel Planner

TravelAI is a full-stack **MERN (MongoDB, Express, React, Node.js)** application that creates hyper-personalized, day-by-day travel itineraries powered by **Google Gemini AI** and verified real-world places from **Google Places & Google Maps Platform**.

---

## 🌟 Key Features

1. **AI-Powered Itineraries**: Multi-day morning, afternoon, and evening structured itineraries generated by Google Gemini 1.5 Flash using verified real-world Google Places context.
2. **Google Places Integration**: Real destination autocomplete, hotel lodging with ratings and addresses, local cuisine restaurants, and tourist attractions.
3. **Interactive Map View**: Embedded Google Maps view with pinpoints for destination center, hotels, dining spots, and itinerary attractions.
4. **Comprehensive Expense Engine & AI Optimizer**:
   - Calculates Accommodation, Transit, Dining, Activities, Local Commute, and Misc expenses.
   - Computes Total Expense, Cost Per Person (`total / travelers`), and Remaining Budget.
   - **Gemini AI Budget Optimizer** suggests specific cost-saving adjustments and estimates potential savings.
5. **Context-Aware AI Travel Concierge**: Floating AI chat assistant that answers questions specifically tailored to the active trip and itinerary.
6. **Full Authentication & Management**:
   - Secure JWT authentication and bcrypt password hashing.
   - Google OAuth support.
   - Trip CRUD: View, customize, add/edit/delete activities, duplicate trips, and generate shareable public links.
   - User Profile management for travel style and currency preferences.

## ⚙️ Environment Variables Setup

### Backend (`server/.env`)

```env
PORT=5000
NODE_ENV=development
MONGODB_URI=mongodb://127.0.0.1:27017/travelai
JWT_SECRET=your_super_secret_jwt_key
JWT_EXPIRES_IN=30d

# Google Gemini API
GEMINI_API_KEY=your_gemini_api_key

# Google Maps / Places Platform
GOOGLE_MAPS_API_KEY=your_google_maps_api_key

# Google OAuth
GOOGLE_CLIENT_ID=your_google_client_id
GOOGLE_CLIENT_SECRET=your_google_client_secret
```

### Frontend (`AITravel/.env`)

```env
VITE_API_BASE_URL=http://localhost:5000/api
VITE_GOOGLE_MAPS_API_KEY=your_google_maps_api_key
VITE_GOOGLE_CLIENT_ID=your_google_client_id
```

## 🚀 Getting Started

### 1. Install Dependencies

**Backend:**
```bash
cd server
npm install
```

**Frontend:**
```bash
cd AITravel
npm install
```

### 2. Run in Development Mode

**Start Backend Server:**
```bash
cd server
npm run dev
# Server runs on http://localhost:5000
```

**Start Frontend Client:**
```bash
cd AITravel
npm run dev
# Vite runs on http://localhost:5173
```

## 🧪 Testing the Complete Flow

1. **Register / Login**: Go to `http://localhost:5173/register` or `http://localhost:5173/login`.
2. **Plan Trip**: Click **Plan New Trip** or search a destination from the home page.
3. **Configure Trip**: Select Destination, Number of Travelers, Dates & Duration, Preferences (Accommodation, Dining, Activities), and Budget limit.
4. **Generate AI Trip**: Click **Generate AI Trip** to trigger the animated AI generation loading screen.
5. **Explore Trip Dashboard**:
   - **Itinerary**: View timeline, add custom activities, delete activities.
   - **Hotels**: View Google Places hotels with ratings, addresses, and price estimates.
   - **Restaurants**: Filter by cuisine or rating, view on map, add to trip.
   - **Places to Visit**: Explore tourist attractions.
   - **Expenses**: View total expense, cost per person, remaining budget, and category breakdowns.
   - **AI Optimizer**: Click *Optimize with AI* for Gemini cost-reduction strategies.
   - **AI Concierge**: Open the chat drawer to ask specific travel questions.
   - **Share**: Click *Share Trip* to copy a shareable link.
6. **My Trips**: Manage, view, duplicate, or delete your saved trips at `/my-trips`.
